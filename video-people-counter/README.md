# 视频人数统计工具

用于医院候诊室患者视频的批量处理：导入视频 → AI 识别人数 → 按人数筛选 → 导出选中视频。

## 使用方法

1. 双击 `视频人数统计.exe` 启动软件
2. 点击 **「📁 导入视频」**，选择视频文件（可多选）
3. 等待 AI 自动处理（提取中间帧 + 识别人数）
4. 点击顶部数字按钮（0~10、10+）筛选对应人数的视频
5. 勾选需要的视频，点击 **「📂 导出选中」**，选择目标文件夹
6. 完成！

## 支持的视频格式

- MP4（主要）
- AVI
- MOV
- MKV
- WMV

## 注意事项

- 首次运行会下载 AI 模型文件（约 6MB），需要联网
- 后续使用完全在本地运行，不需要联网
- 视频不会被上传到任何地方，保护患者隐私
- 导出 = 复制文件到指定文件夹，原始文件不受影响

## 系统要求

- Windows 10 / 11（64 位）
- 不需要安装 Python
