# UI 设计规范

## 设计原则

- **简洁直观**：减少学习成本，一看就会用
- **中文界面**：所有文字使用中文
- **大按钮**：方便点击，适合触摸屏
- **清晰反馈**：操作有进度、有结果提示

## 交互规范

### 导入视频
1. 点击「导入视频」→ 文件对话框打开
2. 用户选择视频文件 → 确认
3. 显示进度条，逐视频处理
4. 处理完成 → 列表自动刷新

### 人数筛选
1. 点击数字按钮 → 按钮高亮（蓝色背景白色文字）
2. 列表即时过滤，只显示匹配项
3. 再次点击同一按钮 → 取消筛选，回到「全部」
4. 「全部」始终可点击，清空所有筛选

### 视频选择
1. 勾选复选框 → 状态栏更新已选数量
2. 点击「全选」→ 勾选当前列表所有可见项
3. 再次点击「全选」→ 取消全部勾选

### 导出视频
1. 点击「导出选中」→ 如果没选视频，提示「请先选择视频」
2. 弹出文件夹选择对话框
3. 确认后开始复制 → 显示进度
4. 完成后弹出提示「导出完成，共 N 个视频」
