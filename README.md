## 人流量视频本地自动筛选工具
### 项目简介
日常运营需每日拍摄医院人流量视频，每月产出 200 + 条素材用于朋友圈宣传推送。因公司共享盘存储空间不足，被要求人工剔除人流量偏少的视频，手动逐条筛查耗时低效，遂用ai开发本本地自动筛选工具。

### 核心功能
1. 本地离线运行，基于 YOLOv8n 轻量视觉模型，无需联网、无接口 Token 消耗、无持续付费
2. 自动读取视频 / 图片素材，截取首帧画面识别人群数量
3. 根据设定人数阈值自动区分合格素材，批量复制至指定输出文件夹
4. 批量处理海量视频文件，替代人工逐条查看筛选，大幅降低重复工作量
### 开发环境
- 编辑器：VSCode
- AI 辅助开发：Claude Code + DeepSeek V4 Pro
- 视觉识别模型：YOLOv8n（本地轻量化模型）
### 优势对比
在线 AI 方案（飞书妙搭 + 豆包）
- 缺点：消耗 Token，过期需续费，长期高频使用成本高，依赖网络，存在平台限制
本本地自研工具
- 优点：一次性极低成本搭建，永久离线免费使用，不受平台涨价、Token 限额、会员制度约束，数据全部本地留存无上传风险
### 使用说明
1. 环境部署完成后，将待筛选视频 / 图片放入输入目录
2. 自定义人流量判定阈值（最低留存人数）
3. 启动程序自动执行画面检测、人数判定
4. 达标的素材自动批量复制至输出文件夹，可直接用于剪辑宣传
### 开源说明
